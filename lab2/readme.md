# Lab 2: Multi-Layer Perceptron (MLP) for Multi-Class Image Classification

This repository contains the implementation and report for **Experiment 2** of the **CS3807 – Deep Learning Laboratory** at **Shiv Nadar University Chennai**.

## Objective

To implement a Multi-Layer Perceptron (MLP) using TensorFlow/Keras for multi-class image classification on the Fashion-MNIST dataset and improve its performance through automated hyperparameter optimization.

## Contents

- `lab2.ipynb` – Complete implementation of the experiment
- `lab2.tex` – LaTeX source of the laboratory report
- `lab2.pdf` – Final compiled laboratory report
- `README.md` – Overview of the experiment

## Topics Covered

- Fashion-MNIST dataset exploration
- Image preprocessing and normalization
- MLP model construction and training
- Model evaluation using classification metrics
- Hyperparameter optimization with RandomizedSearchCV (SciKeras)
- Performance comparison between baseline and optimized models
- Visualization of training results and evaluation metrics

## Tools & Libraries

- Python
- TensorFlow / Keras
- SciKeras
- Scikit-learn
- NumPy
- Matplotlib
- Pandas
