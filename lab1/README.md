# Lab 1: Single Layer Perceptron for Binary Classification

This repository contains the implementation and report for **Experiment 1** of the **CS3807 – Deep Learning Laboratory** at **Shiv Nadar University Chennai**.

## Objective

To implement a Single Layer Perceptron from scratch for binary classification, understand the perceptron learning algorithm, visualize the learning process, and evaluate the model using the Banknote Authentication dataset.

## Contents

- `lab1.ipynb` – Complete implementation of the experiment
- `lab1.tex` – LaTeX source of the laboratory report
- `lab1.pdf` – Final compiled laboratory report
- `README.md` – Overview of the experiment

## Topics Covered

- Banknote Authentication dataset exploration
- Exploratory Data Analysis (EDA)
- Data preprocessing and normalization
- Single Layer Perceptron implementation from scratch
- Perceptron learning rule and weight updates
- Model evaluation using classification metrics
- Learning rate comparison
- Visualization of training process and decision boundary
- Implementation of Perceptron for AND, OR, NOT, and XOR logic gates

## Tools & Libraries

- Python
- NumPy
- Pandas
- Matplotlib
- Scikit-learn
